## Tentang Website

Website ini dibuat untuk menghadirkan layanan informasi Snapmoo Photobooth Portable Tegal dalam bentuk platform digital yang mudah diakses oleh masyarakat. Melalui website, pengunjung dapat mengenal usaha, melihat hasil dokumentasi dari berbagai acara, mengetahui layanan yang tersedia, serta memperoleh informasi kontak dan lokasi tanpa harus datang langsung.

Website juga dirancang agar dapat menjadi media promosi yang mampu meningkatkan jangkauan pemasaran serta memudahkan pelanggan dalam memperoleh informasi mengenai jasa photobooth yang ditawarkan.

## Fitur yang Tersedia

* Informasi mengenai Snapmoo Photobooth.
* Tampilan galeri hasil dokumentasi acara.
* Penjelasan layanan dan paket yang ditawarkan.
* Informasi jam operasional dan alamat.
* Kontak yang dapat dihubungi.
* Desain responsif sehingga nyaman diakses melalui berbagai perangkat.

## Dibangun Menggunakan

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* Bootstrap Icons
* Google Fonts

## Cara Mengakses Website

1. Unduh repository project ke komputer.
2. Buka folder project setelah proses download selesai.
3. Jalankan file **index.html** menggunakan browser favorit, seperti Google Chrome, Microsoft Edge, atau Mozilla Firefox.
4. Website siap digunakan tanpa konfigurasi tambahan.

## Tujuan Pengembangan

Website ini dikembangkan sebagai implementasi pemanfaatan teknologi web dalam mendukung promosi UMKM. Dengan adanya platform ini, informasi mengenai Snapmoo Photobooth Portable Tegal dapat disampaikan dengan lebih cepat, mudah diakses, dan menjangkau lebih banyak calon pelanggan dibandingkan media promosi konvensional.
